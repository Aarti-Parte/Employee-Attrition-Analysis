# Employee Attrition Analysis Using Python

## Project Overview
This project analyzes employee attrition using Python. The goal is to understand employee turnover patterns and identify departments and work conditions associated with higher attrition rates.

## Dataset
- Total Employees: 1,470
- Total Columns: 35
- Missing Values: 0
- Duplicate Rows: 0

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Analysis Performed
1. Dataset loading and inspection
2. Missing value and duplicate checking
3. Overall employee attrition analysis
4. Department-wise attrition analysis
5. Gender-wise attrition analysis
6. Overtime-wise attrition analysis
7. Data visualization using bar charts

## Key Findings
- Total employees analyzed: 1,470
- Employees who left: 237
- Employees who stayed: 1,233
- Overall attrition rate: 16.12%
- Sales had the highest department-wise attrition rate at 20.63%.
- Research & Development had the lowest department-wise attrition rate at 13.84%.
- Employees who worked overtime had an attrition rate of 30.53%, compared with 10.44% for employees who did not work overtime.

## Conclusion
The analysis found differences in attrition rates across departments and overtime categories. These findings can help identify areas for further investigation into employee retention.

The results show associations in the dataset and do not establish the causes of employee attrition.

## How to Run the Project
1. Install Python.
2. Install the required libraries:

   `python -m pip install pandas matplotlib`

3. Keep the dataset CSV file in the same folder as the Python script.
4. Run the project:

   `python employee_attrition.py`
